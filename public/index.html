    LOKY AI

    Created by Lokesh Yadav

    LOKY AI Next is a fast, mobile-first AI assistant. Answers stream in real time, Markdown and code blocks are rendered and highlighted, and your conversations stay in this browser.

    • Streaming responses over Server-Sent Events
    • Markdown rendering with syntax-highlighted code and one-click copy
    • Local chat history — titles, timestamps, rename, reopen and delete
    • Dark theme, accessible and reduced-motion friendly

    Your API key is never exposed to the browser. The server talks to the AI provider on your behalf.
